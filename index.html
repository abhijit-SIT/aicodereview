How It Works

Analysis Pipeline Architecture

From source ingestion to deep security checks and AI patch generation.

01
📄

AST Ingestion

Parses abstract syntax trees to build a symbol hierarchy, tracking variable assignments and function calls.

02
🛡️

OWASP Auditing

Scans for injection vectors (SQL, Command), unsafe deserialization, hardcoded secrets, and cross-site scripting.

03
⚡

Resource Profiling

Identifies unclosed handles, thread leaks, swallowed exceptions, and concurrency race conditions.

04
🤖

Patch Synthesis

Synthesizes idiomatic, safe refactor snippets with modern language idioms ready to copy into your codebase.

Engine Capabilities

Developer Quickstart

Run AI Code Reviewer Locally

You can run the full Java review engine straight from your terminal.

# 1. Clone the repository
$ git clone https://github.com/abhijit-SIT/aicodereview.git
$ cd aicodereview

# 2. Build and run automated tests
$ mvn clean test

# 3. Launch the review application
$ mvn exec:java -Dexec.mainClass="com.aicodereview.App"
